A practical guide to the features supported by this experimental interpreter.
Flux is experimental. Lists, records and return values are supported; imports and a standard library are not yet available.
Flux is experimental and not intended for untrusted or production workloads. Programs are run in an isolated worker with a time limit; this is not a security sandbox.
